🟢 네이버 블로그
네이버 로그인 방식: Playwright 브라우저 자동화로 직접 로그인합니다.
서버 .env 설정: NAVER_ID, NAVER_PW, NAVER_BLOG_ID
주의: 2단계 인증이 활성화된 경우 첫 로그인 후 신뢰 기기로 등록해두세요.
🟠 티스토리
Playwright 자동 로그인 방식 — 토큰 만료 없음
Railway 환경변수에 아래 3개 설정하면 자동 발행됩니다:
TISTORY_ID 카카오 이메일
TISTORY_PW 카카오 비번
TISTORY_BLOG_NAME 블로그 주소 앞부분 (예: myblog.tistory.com → myblog)
🔵 블로그스팟 (Google Blogger)
아래 버튼 한 번만 클릭 → 구글 계정 선택 → 허용.
리프레시 토큰이 서버에 영구 저장되어 이후 자동 발행됨.
※ Railway에 BLOGGER_CLIENT_ID / BLOGGER_CLIENT_SECRET 설정 필요

🔑 API 키 · 계정 연결

📄 애드센스 필수 페이지
소개 · 개인정보처리방침 · 문의하기 3개가 없으면 글을 아무리 많이 써도 신뢰도 부족으로 승인이 거절됩니다.
아래 버튼 한 번이면 3개가 순서대로 발행됩니다.
💰 제휴 수익 추적 ID (이거 없으면 수익 0원)
상품 링크에 내 추적 ID가 붙어야 "누가 소개해서 팔렸는지"가 기록되고 수익이 들어옵니다. 없으면 독자가 아무리 사도 0원입니다.
쿠팡파트너스 — partners.coupang.com 가입(대개 즉시~하루) → 내 아이디(AF로 시작) 복사. 애드센스와 달리 심사 대기가 거의 없어 일주일 안에 수익이 가능한 유일한 경로입니다.
🍪 네이버·티스토리 쿠키 로그인 (권장)
네이버·카카오는 자동 로그인을 막습니다. 아이디·비밀번호 방식은 캡차·기기 인증 때문에 계속 깨져요.
이미 로그인된 쿠키를 넣으면 로그인 단계를 통째로 건너뛰어 훨씬 안정적입니다. 한 번 넣으면 몇 주~몇 달 갑니다.
넣는 법 — PC 크롬에서 네이버(또는 티스토리) 로그인 → F12 → Application → Cookies → 해당 도메인 선택 → 전체 복사. 확장앱(EditThisCookie 등)의 JSON 내보내기도 그대로 됩니다.
🔍 플랫폼 실제 연결 테스트
자격증명이 실제로 유효한지 확인합니다. 발행이 안 될 때 여기서 원인을 찾으세요.
💳 글 생성 비용 · 잔액
지금 글을 쓸 수 있는 상태인지를 실제 호출로 확인합니다. 잔액이 바닥나면 여기서 바로 걸립니다.
쓴 금액은 관리자 키가 있어야 보입니다 (조직 계정만 발급 가능). 없어도 위 확인은 됩니다.
✍️ 글 생성 테스트
실제로 글 하나를 만들어봅니다. 발행은 하지 않습니다. 글이 안 써지는 이유가 키 문제인지, 잔액인지, 생성 자체인지 단계별로 갈립니다. (1~3분)
🚀 진짜 발행 테스트
짧은 테스트 글 하나를 실제로 올려봅니다. 글 생성(AI)은 건너뛰기 때문에, "글이 안 올라간다"의 원인이 생성인지 발행인지 바로 갈립니다. 블로그별로 성공 여부와 오류 메시지를 그대로 보여줍니다. (최대 2분)
🔒 다시는 안 끊기게 (1회만)
지금 연결된 정보를 값 하나로 묶어드립니다. Railway → Variables 에 CREDENTIALS_BLOB 이름으로 한 번만 붙여넣으면, 재배포하든 서버가 죽었다 살아나든 연결이 그대로 유지됩니다. 볼륨도 필요 없습니다.
🧾 서버가 겪은 오류
서버에서 실제로 난 오류가 최신순으로 쌓입니다. 뭔가 안 될 때 여기만 보면 됩니다. 비밀번호·토큰 같은 값은 지운 채로만 보여줍니다.
